# EasyEffects Preset

Custom EasyEffects preset tuned specifically for my device (**Edifier P180** so far)

## Output Preset

### 1. Edifier P180

Karakter suara udah nggak terlalu V-shaped dan nggak terlalu mendut-mendut, tapi bass-nya tetep dapet. Buat drum, snare-nya cenderung berbobot tapi kick-nya nggak terlalu dalam. Vokalnya cukup terbuka dan udah ngepas banget buat dengerin Chevy. Bagian treble-nya smooth, jadi nggak bikin ngecring-ngecring di cymbal (Maap kalau ada yg ngaco, kuping saya kaleng).
