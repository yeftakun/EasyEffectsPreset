# EasyEffects Preset - Edifier P180 Pro

Custom EasyEffects preset tuned specifically for **Edifier P180** (so far)

## Preset

### 1. Edifier P180 - Perfect EQ

Karakter suara Udah ga terlalu V-shaped dan ga mendut-mendut, tapi bass-nya tetep dapet. Buat drum, yg snare cenderung ngebas tapi kick ga terlalu dalam. Buat vokal cukup terbuka suaranya, buat dengerin Chevy dah ngepas. Untuk treble smooth dan ga terlalu ngecring-ngecring di snare drum.
